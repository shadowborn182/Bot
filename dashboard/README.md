# Dashboard (Next.js)

This is a minimal Next.js scaffold for the dashboard frontend. It uses the Express backend (server/) for authentication and API.

.env variables (dashboard/.env.local):
- API_BASE_URL (e.g. https://api.yourdomain.com)

Run (dev):
1. cd dashboard
2. npm install
3. npm run dev

The dashboard expects the server to be reachable at API_BASE_URL for auth and API calls.
